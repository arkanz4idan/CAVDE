# Coding Standard

## General

- Python 3.12+
- Type hints required
- UTF-8 encoding
- One class per responsibility

---

## Naming

Classes

```python
PascalCase
```

Functions

```python
snake_case
```

Constants

```python
UPPER_CASE
```

---

## Rules

- No circular imports
- Keep modules focused
- Prefer composition over inheritance where appropriate
- Document public classes and functions
- Test after every completed subsystem
